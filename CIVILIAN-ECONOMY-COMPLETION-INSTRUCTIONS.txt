1. Back up your current project.
2. Extract this ZIP over C:\Projects\ultimatecad and replace files.
3. Run only this new migration in Supabase SQL Editor:
   supabase/migrations/202608060008_civilian_economy_completion.sql
4. Build:
   rmdir /s /q .next
   pnpm build
5. Push:
   git add .
