ULTIMATECAD — MILESTONE 1.0 LANDING PAGE

1. Extract this ZIP into:
   C:\Projects\ultimatecad

2. Allow Windows to merge folders and replace files.

3. Keep your existing .env.local file. It is intentionally not included.

4. Run:
   cd C:\Projects\ultimatecad
   rmdir /s /q .next
   pnpm install
   pnpm build

5. If the build succeeds:
   git add .
   git commit -m "feat: add detailed commercial UltimateCAD landing page"
   git push origin main
