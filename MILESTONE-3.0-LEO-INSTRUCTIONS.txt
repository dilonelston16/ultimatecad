ULTIMATECAD MILESTONE 3.0 — LEO / MDT FOUNDATION

INSTALL

1. Extract into:
   C:\Projects\ultimatecad

2. Run in Supabase SQL Editor:
   supabase/migrations/202608060018_leo_mdt_foundation.sql

3. Build:
   cd C:\Projects\ultimatecad
   rmdir /s /q .next
   pnpm build

4. Push:
   git add .
   git commit -m "feat: add LEO MDT foundation"
   git push origin main
